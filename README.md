# task-4-of-apexplanet
# Final Business Intelligence & Analytics Presentation

## Objective

The objective of this project was to analyze sales data, generate business insights, and create interactive dashboards using Business Intelligence tools.

## Tools Used

* SQL Server
* Excel
* Power BI
* GitHub

## Project Workflow

1. Data Cleaning & Wrangling
2. Exploratory Data Analysis
3. KPI Development
4. Interactive Dashboard Creation
5. Customer Segmentation Analysis
6. Hypothesis Testing
7. Business Recommendations

## Core KPIs

* Total Sales
* Total Orders
* Average Sales
* Total Quantity Sold

## Deep-Dive Analysis

Customer Segmentation Analysis was performed to identify high-value customers and sales contribution patterns.

## Hypothesis Testing

A T-Test was performed to analyze whether customer type significantly impacts sales performance.

### Result

* p-value < 0.05
* Customer type significantly affects sales.

## Outcome

The project successfully demonstrated how Business Intelligence and Data Analytics techniques can support better business decision-making and performance monitoring.
